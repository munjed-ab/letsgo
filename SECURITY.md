# Security

## What to expect

letsgo is designed for a home network you trust and has **no login and no encryption**. Read
[docs/privacy-and-security.md](docs/privacy-and-security.md) for what that means, what is protected
(web pages cannot drive a device) and what is not (any program on the same network can). Please do not
use it on public or shared Wi-Fi.

## Reporting a vulnerability

If you find a way to do more than that page describes (for example to read or write files outside the
music folders, run code on a device, or make a device reach something off your network), please report
it **privately** to the maintainer before making it public, with the steps to reproduce it. Use the
"report a vulnerability" feature of the site that hosts this repository if it has one, or the contact
on the maintainer's profile there. If there is no private channel, open an issue that says you have a
security report and asks for one, without the details.

You will get an answer as soon as the maintainer can give one. This is a small volunteer project, so there
is no fixed response time and no bounty.

## Supported versions

Only the latest commit on the main branch.
